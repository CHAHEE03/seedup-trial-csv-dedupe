# Seedup 목표 (프로젝트 prd:3aa85535-68de-4a51-b702-6ad0a6374fd7)

목표 v1 (A 개인용): CSV를 자주 합치는 1인 개발자가 중복 행을 손으로 찾지 않고 명령 한 줄로 지우고, 몇 개를 지웠는지 바로 안다.
⬜ G-1 헤더를 지키고 완전히 같은 행 중 첫 행만 남긴다 (재는 방법: 중복 2줄이 있는 CSV 테스트에서 출력이 헤더 1줄과 데이터 2줄)
⬜ G-2 지운 행과 남긴 행 개수를 출력한다 (재는 방법: 테스트에서 표준 출력이 removed: N, kept: M 두 줄)
⬜ G-3 원본 파일을 덮어쓰지 않는다 (재는 방법: 실행 뒤 원본 파일 내용이 그대로인지 테스트로 확인)
하지 않는 것: 웹 화면 / xlsx 파일 / 퍼지 매칭 / 외부 패키지

세션을 시작하면 Seedup MCP의 get_next_task를 slug "prd:3aa85535-68de-4a51-b702-6ad0a6374fd7"로 먼저 부르고, 그 기능 하나만 만드세요.
하지 않는 것에 해당하거나 성공 기준과 무관한 작업이면 시작하기 전에 사용자에게 물어보세요.
이 파일은 목표 v1의 사본입니다. 목표가 바뀌면 Seedup에서 훅 묶음을 다시 받으세요.

## 사람이 먼저 할 일
- H-1 차별점을 무엇으로 잡을지. 원문과 비교 대상 도구 설명이 없어 정하지 않았다. 후보로 "헤더를 지킨 첫 행 유지와 지운 개수 동시 출력"이 있는데, 같은 일을 하는 다른 도구가 있는지 확인한 뒤 정한다.
- H-2 집계 결과를 --json으로도 낼지. 다른 스크립트에서 횟수를 읽으려면 기계가 읽을 형식이 필요하다.
- H-3 헤더 자동 감지가 필요한지. 첫 줄이 나머지와 값이 겹치지 않으면 헤더로 추정하는 규칙을 넣을지 정하지 않았다.
- H-4 100MB를 넘는 파일에 스트리밍 처리를 붙일지.
- H-5 열 개수가 헤더와 다른 행을 경고만 하고 통과시킬지, 기본값으로 건너뛸지.

## 에이전트 훅 켜기 (Claude Code · Codex · Windows)
훅은 sh 없이 Node로 `.seedup/hook.mjs`를 실행하므로 macOS · Linux · Windows에서 같은 묶음을 씁니다(Node 필요).
- Claude Code: `.claude/settings.json`을 저장소에 넣거나 기존 `hooks`에 합치세요.
- Codex CLI: `.codex/hooks.json`을 저장소에 넣은 뒤, 세션에서 `/hooks`를 열어 현재 훅 정의를 검토하고 신뢰해야 실행됩니다.

## 커밋 전 검사 켜기
커밋하기 전에 추가된 줄을 검사합니다(시크릿, 건너뛴 테스트, not implemented 예외는 커밋을 막고, 나머지는 경고만). Node가 있어야 합니다.
이미 pre-commit 훅이 없다면 한 번만 실행하세요: `cp .seedup/pre-commit.sh .git/hooks/pre-commit && chmod +x .git/hooks/pre-commit`
이미 있거나(husky 등) sh가 없는 Windows 환경이라면 커밋 전 훅에 `node .seedup/hook.mjs pre-commit` 한 줄을 더하세요.
의도한 예외는 그 줄이나 바로 윗줄에 `// seedup-allow: <코드> <이유>`를 적습니다.
